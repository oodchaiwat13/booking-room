# ระบบจองห้อง (Google Apps Script)

ระบบจองห้องเรียน ห้องประชุม และห้องปฏิบัติการ ใช้ Google Sheets เป็นฐานข้อมูล และ Apps Script เป็น Web App

## ฟีเจอร์

- **หน้าจอง**: เลือกห้อง วันที่ เวลา สังกัด สถานภาพ ชื่อ-สกุล และวัตถุประสงค์ ถ้าเวลาชนกับการจองเดิมจะแจ้งเตือนและกดจองไม่ได้
- **แดชบอร์ด**: แสดงสถานะ ว่าง / ไม่ว่าง ของทุกห้อง พร้อมชื่อผู้จอง ห้องที่ไม่ว่างจะไม่มีปุ่มจอง
- **หน้าไทม์ไลน์** (`?page=dashboard`): แสดงแถบเวลารายห้อง (07:00–21:00) บอกว่าห้องว่างถึงกี่โมง หรือใช้ถึงกี่โมง รีเฟรชเองทุก 1 นาที เหมาะกับเปิดค้างบนจอ
- **สถิติปีงบประมาณ**: สรุปจำนวนครั้งและชั่วโมงการใช้ห้อง แยกรายเดือน ตามห้อง ตามสังกัด และตามสถานภาพ

## โครงสร้างไฟล์

| ไฟล์ | ชนิดใน Apps Script | หน้าที่ |
|---|---|---|
| `Code.gs` | Script | ฝั่งเซิร์ฟเวอร์ ทั้งหมดของตรรกะและการอ่าน/เขียนชีต |
| `Index` | HTML | หน้าจอง + แดชบอร์ดแบบการ์ด + สถิติ (3 แท็บ) |
| `Dashboard` | HTML | หน้าไทม์ไลน์รายห้อง |

ชื่อไฟล์ HTML ต้องเป็น `Index` และ `Dashboard` เท่านั้น (ไม่ต้องใส่ `.html`)

## สถาปัตยกรรม

```
 ผู้ใช้
  ├─ .../exec                 ──►  Index.html      (จอง / แดชบอร์ด / สถิติ)
  └─ .../exec?page=dashboard  ──►  Dashboard.html  (ไทม์ไลน์)
                                        │  google.script.run
                                        ▼
                                   Code.gs (Apps Script)
                                        │
                                        ▼
                             Google Sheets : ชีต "Bookings"
```

### ฟังก์ชันใน Code.gs

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `doGet(e)` | ดูพารามิเตอร์ `page` แล้วส่งหน้าที่ถูกต้อง ถ้าไม่พบไฟล์ HTML จะแสดงข้อความบอกชื่อไฟล์ที่ต้องสร้าง |
| `getConfig()` | ส่งรายชื่อห้อง สังกัด สถานภาพ วันที่ปัจจุบัน และปีงบประมาณปัจจุบัน |
| `getBookings(date)` | ดึงรายการจองสถานะ "ใช้งาน" ของวันที่เลือก |
| `submitBooking(b)` | ตรวจข้อมูล ตรวจเวลาชนภายใต้ `LockService` แล้วบันทึกแถวใหม่ |
| `cancelBooking(id, name)` | ยกเลิกการจองเมื่อชื่อตรงกับผู้จอง (ยังไม่มีปุ่มในหน้าเว็บ) |
| `getStats(fy)` | รวมสถิติตามปีงบประมาณที่เลือก |

## ฐานข้อมูล (ชีต `Bookings`)

ชีตถูกสร้างอัตโนมัติเมื่อมีการเรียกใช้ครั้งแรก 1 การจอง = 1 แถว

| คอลัมน์ | ความหมาย |
|---|---|
| A ID | รหัสการจอง (8 ตัวอักษร) |
| B บันทึกเมื่อ | วันเวลาที่กดจอง |
| C ห้อง | ชื่อห้อง |
| D กลุ่มห้อง | เช่น ห้องปฏิบัติการชั้น 2 |
| E สังกัด | สังกัดผู้จอง |
| F ชื่อ-สกุล | ผู้จอง |
| G สถานภาพ | นักศึกษา / อาจารย์ / พนักงาน |
| H วันที่ | รูปแบบ `yyyy-MM-dd` (เก็บเป็นข้อความ) |
| I เริ่ม | รูปแบบ `HH:mm` |
| J สิ้นสุด | รูปแบบ `HH:mm` |
| K วัตถุประสงค์ | ข้อความอิสระ |
| L สถานะ | `ใช้งาน` หรือ `ยกเลิก` |
| M ปีงบประมาณ | ปี พ.ศ. ตามปีงบประมาณไทย |

## กติกาของระบบ

- **เวลาชน**: การจองชนกันเมื่อห้องและวันเดียวกัน และ `เริ่มใหม่ < สิ้นสุดเดิม` และ `สิ้นสุดใหม่ > เริ่มเดิม` (จองต่อเนื่องกันพอดีได้)
- **จองย้อนหลัง**: ไม่อนุญาต
- **ปีงบประมาณ**: 1 ต.ค. – 30 ก.ย. เดือน ต.ค.–ธ.ค. นับเป็นปีถัดไป และแสดงเป็น พ.ศ.
- **สถานะ "ไม่ว่าง" บนแดชบอร์ด**: คำนวณจากเวลาปัจจุบันของเครื่องผู้ใช้ ถ้าวันที่เลือกไม่ใช่วันนี้ จะแสดงจำนวนรายการจองแทน
- **ช่วงเวลาไทม์ไลน์**: แก้ที่ค่า `START` และ `END` ในสคริปต์ของ `Dashboard.html`

## การติดตั้ง

1. สร้าง Google Sheets ใหม่ แล้วเปิด ส่วนขยาย > Apps Script
2. วางโค้ด `Code.gs` ลงไฟล์ `Code.gs`
3. กด **+** ข้างคำว่า "ไฟล์" เลือก **HTML** ตั้งชื่อ `Index` แล้ววางโค้ดจาก `Index.html`
4. ทำซ้ำ ตั้งชื่อ `Dashboard` แล้ววางโค้ดจาก `Dashboard.html`
5. กด Deploy > New deployment > ประเภท Web app
   - Execute as: Me
   - Who has access: ตามที่ต้องการ (เช่น ทุกคนในองค์กร หรือ Anyone)
6. คัดลอกลิงก์ `/exec` ไปใช้งาน

เมื่อแก้โค้ดภายหลัง ต้อง Deploy > Manage deployments > Edit > Version: New version > Deploy ทุกครั้ง มิฉะนั้นลิงก์เดิมจะยังใช้โค้ดเก่า

## ลิงก์ที่ใช้งาน

| ลิงก์ | หน้า |
|---|---|
| `https://script.google.com/macros/s/<ID>/exec` | จอง / แดชบอร์ด / สถิติ |
| `https://script.google.com/macros/s/<ID>/exec?page=dashboard` | ไทม์ไลน์ (เปิดบนจอทีวี) |

## การแก้ปัญหา

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| ขึ้นข้อความ "ไม่พบไฟล์ HTML ชื่อ ..." | ยังไม่ได้สร้างไฟล์ `Index` หรือ `Dashboard` ผ่านเมนู + > HTML หรือสะกดชื่อไม่ตรง |
| แก้โค้ดแล้วหน้าเว็บไม่เปลี่ยน | ยังไม่ได้ Deploy เวอร์ชันใหม่ |
| ไฟล์อยู่ในโปรเจกต์แต่ยังหาไม่เจอ | เปิดคนละโปรเจกต์กับที่ Deploy |
| จองไม่ได้ ขึ้น "ห้องไม่ว่าง" | เวลาชนกับการจองเดิม ดูรายการจองในวันนั้นที่หน้าจอง |
| ชีต `Bookings` ไม่ถูกสร้าง | ยังไม่มีการเรียกใช้ระบบ ลองเปิดลิงก์ `/exec` หนึ่งครั้ง และตรวจว่า Apps Script ผูกกับ Google Sheets (สร้างจากเมนูในชีต) |

## ข้อจำกัดและแนวทางต่อยอด

- ยังไม่มีระบบล็อกอิน ใครมีลิงก์ก็จองได้ (ถ้าต้องการจำกัดเฉพาะอีเมลมหาวิทยาลัย สามารถเพิ่มการตรวจสอบได้)
- ยังไม่มีปุ่มยกเลิกในหน้าเว็บ (มีฟังก์ชัน `cancelBooking` รองรับแล้ว)
- ยังไม่มีการจองซ้ำรายสัปดาห์ และไม่มีอีเมลแจ้งเตือนผู้จอง
